# Rock, Paper, Scissors

A command-line Rock, Paper, Scissors game in Python, played against the computer.

## About this project

The first version is still in this repository's commit history.

## What I practiced

- Loops (`while`) and `if` / `elif` / `else`
- Getting user input with `input()`
- Using the `random` module
- Reading and understanding code written by someone else

## What changed in the improved version

- `quit` works in any capitalization
- Extra spaces in the input are ignored
- Invalid input shows an error message instead of playing a round
- A goodbye message when the game ends

## How to run

You need Python 3 installed. In a terminal, run:

    python main.py
